# Развёртывание WeldTeam MES на Windows Server (локальная сеть цеха)

Пошаговая инструкция: как подключиться к серверу по RDP и запустить сайт так,
чтобы он был доступен другим компьютерам и телефонам внутри заводской сети.

> **Самое важное про данные.** В git лежит только код и справочники. Вся реальная
> работа — Weld Balance, дефекты, оборудование, учётные записи — в файле
> **`data/welding_shop.db`**, которого в git НЕТ. Его нужно **скопировать на сервер
> отдельно** (шаг 4), иначе на сервере будет почти пустая база.

---

## Установка одним скриптом (рекомендуется)

Скрипт `deploy/install.ps1` делает всё сам: ставит **Python** и **Git** (если их нет),
скачивает код, поднимает окружение и зависимости, создаёт `.env` со случайным секретным
ключом, при необходимости строит пустую БД, регистрирует **службу Windows** (автостарт
при загрузке + авто-перезапуск при падении) и открывает порт в брандмауэре. Повторный
запуск безопасен — он обновит код и перезапустит службу.

**Шаги:**

1. Подключитесь к серверу по RDP (Win+R → `mstsc` → адрес, логин, пароль).
2. Откройте **PowerShell от имени администратора** (правой кнопкой → «Запуск от имени администратора»).
3. Выполните команду (это ОДНА строка — скопируйте целиком; две части разделены `;`):
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass -Force; iwr -useb https://raw.githubusercontent.com/Al1l-plup/-WT-/DEV/deploy/install.ps1 | iex
   ```
   *(Если вводите вручную — сначала `Set-ExecutionPolicy -Scope Process Bypass -Force`,
   Enter, затем `iwr -useb …/install.ps1 | iex`, Enter. На одной строке без `;` PowerShell
   выдаст ошибку «Не удается найти позиционный параметр… iwr».)*
   Всё установится в `C:\WeldTeam`, служба запустится. В конце скрипт покажет адрес вида
   `http://192.168.X.X:5000` — по нему заходят из сети цеха.

   *Если репозиторий приватный и строка выше не сработала — сначала клонируйте, потом
   запустите локальный скрипт:*
   ```powershell
   git clone -b DEV https://github.com/Al1l-plup/-WT-.git C:\WeldTeam
   C:\WeldTeam\deploy\install.ps1
   ```
4. **Перенесите реальную базу:** скопируйте `data\welding_shop.db` с рабочего ПК в
   `C:\WeldTeam\data\` (перезаписав пустую), затем перезапустите службу:
   ```powershell
   C:\WeldTeam\deploy\nssm.exe restart WeldTeamMES
   ```

Готово — сайт работает и **поднимается сам после каждой перезагрузки** сервера.

**Обновление до новой версии** (после того как запушили правки в `DEV`):
```powershell
powershell -ExecutionPolicy Bypass -File C:\WeldTeam\deploy\update.ps1
```
> `update.ps1` работает, только если проект скачан через Git. Если ставили и на сервере
> НЕ было Git (код скачался ZIP-архивом), один раз выполните конвертацию в git-репозиторий
> (ставит Git, бэкапит `.env` и базу, ничего не теряет):
> ```powershell
> Set-ExecutionPolicy -Scope Process Bypass -Force; iwr -useb https://raw.githubusercontent.com/Al1l-plup/-WT-/DEV/deploy/setup_git.ps1 | iex
> ```
> После этого обновления идут лёгкой командой `update.ps1` выше. Пока не сконвертировали —
> обновляйтесь повторным запуском `install.ps1` (тоже сохраняет базу и `.env`).

**Управление службой:**
- Статус: `Get-Service WeldTeamMES` · Перезапуск: `Restart-Service WeldTeamMES`
- Логи сервера: `C:\WeldTeam\logs\server.log`

> Ниже — та же установка **вручную по шагам**, если скрипт по какой-то причине не подошёл.

## Что понадобится

- Адрес (IP или имя) сервера, логин и пароль от него.
- На сервере — интернет (для установки Python и зависимостей) хотя бы на время настройки.
- Ваш рабочий файл `data/welding_shop.db` (актуальная база с этого компьютера).

---

## Шаг 1. Подключиться к серверу по RDP

1. На своём компьютере нажмите **Win + R**, введите `mstsc`, Enter.
2. В «Компьютер» впишите адрес сервера → **Подключить**.
3. Введите логин и пароль от сервера.
4. *(Удобно сразу настроить передачу файлов:* в окне «Подключение к удалённому
   рабочему столу» → **Показать параметры → Локальные ресурсы → Подробнее →
   Устройства** — отметьте свой диск `C:`. Тогда с сервера будет виден ваш диск,
   и файлы (проект, БД) можно перетащить копированием.)

---

## Шаг 2. Установить Python 3.11+ на сервере

1. На сервере откройте браузер → <https://www.python.org/downloads/windows/>.
2. Скачайте **Python 3.11** (или новее), запустите установщик.
3. **ОБЯЗАТЕЛЬНО** отметьте галочку **«Add python.exe to PATH»**, затем «Install Now».
4. Проверка: откройте **PowerShell** (или cmd) и введите `python --version` — должна
   показаться версия.

---

## Шаг 3. Скопировать проект на сервер

Папку положим, например, в `C:\WeldTeam`.

**Вариант А — через Git** (если установите Git с <https://git-scm.com>):
```powershell
cd C:\
git clone https://github.com/Al1l-plup/-WT-.git WeldTeam
cd C:\WeldTeam
git checkout DEV
```

**Вариант Б — просто копированием:** заархивируйте папку проекта `-WT-` на своём
ПК (без папок `.venv`, `data`, `backups` — их не переносим), перетащите архив на
сервер (через проброшенный диск из шага 1) и распакуйте в `C:\WeldTeam`.

---

## Шаг 4. Перенести базу данных (КРИТИЧНО)

1. На своём ПК возьмите файл `C:\Users\al.galimov\-WT-\data\welding_shop.db`.
2. Скопируйте его на сервер в `C:\WeldTeam\data\welding_shop.db`
   (папку `data` создайте, если её нет).

Без этого шага сайт запустится, но будет пустым.

---

## Шаг 5. Создать окружение и установить зависимости

На сервере в PowerShell:
```powershell
cd C:\WeldTeam
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

---

## Шаг 6. Настроить `.env` (секретный ключ)

1. Скопируйте `.env.example` в `.env` (в папке `C:\WeldTeam`).
2. Сгенерируйте секретный ключ:
   ```powershell
   .venv\Scripts\python -c "import secrets; print(secrets.token_hex(32))"
   ```
3. Откройте `.env` Блокнотом, вставьте полученную строку в `SECRET_KEY=...`,
   убедитесь что `FLASK_ENV=production`. Сохраните.

> Смена `SECRET_KEY` обязательна: со стандартным ключом чужой человек в сети мог бы
> подделать вход. Это единственная обязательная правка для безопасности.

---

## Шаг 7. Первый запуск и проверка

Запустите `ЗАПУСК.bat` двойным кликом (или в PowerShell `.\ЗАПУСК.bat`).
В окне появится строка вида:
```
👉 ДЛЯ ВХОДА С ТЕЛЕФОНА ВВЕДИТЕ: http://192.168.X.X:5000
```
На самом сервере откройте `http://127.0.0.1:5000` — должна открыться страница входа.
Запишите IP-адрес (192.168.X.X) — по нему заходят с других устройств.

Окно закрывать нельзя, пока оно открыто — сайт работает. Автозапуск без окна — шаг 9.

---

## Шаг 8. Открыть порт 5000 в брандмауэре

Чтобы сайт был виден другим ПК в сети, один раз разрешите порт. В PowerShell
**от имени администратора**:
```powershell
New-NetFirewallRule -DisplayName "WeldTeam MES 5000" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
```

---

## Шаг 9. Автозапуск (чтобы работал без входа в сервер)

Чтобы сайт поднимался сам после перезагрузки сервера — удобнее всего служба Windows
через **NSSM** (Non-Sucking Service Manager):

1. Скачайте NSSM: <https://nssm.cc/download>, распакуйте, скопируйте `nssm.exe`
   в `C:\WeldTeam`.
2. В PowerShell **от администратора**:
   ```powershell
   cd C:\WeldTeam
   .\nssm.exe install WeldTeamMES "C:\WeldTeam\.venv\Scripts\python.exe" "C:\WeldTeam\wsgi.py"
   .\nssm.exe set WeldTeamMES AppDirectory "C:\WeldTeam"
   .\nssm.exe set WeldTeamMES Start SERVICE_AUTO_START
   .\nssm.exe start WeldTeamMES
   ```
3. Теперь сайт работает как служба и стартует при загрузке сервера.
   Управление: `nssm.exe stop/start/restart WeldTeamMES`.

*(Проще, но менее надёжно — «Планировщик заданий»: создать задачу «При запуске
компьютера», действие — запуск `ЗАПУСК.bat`.)*

---

## Доступ с других компьютеров и телефонов

В браузере на устройстве той же сети: **`http://<IP-сервера>:5000`**
(например `http://192.168.10.5:5000`). Первый вход — регистрация; аккаунт
`al.galimov@astana-motors.kz` автоматически получает права администратора.

---

## Обновление версии (когда выйдут новые правки)

```powershell
cd C:\WeldTeam
git pull                                   # если ставили через Git
.venv\Scripts\pip install -r requirements.txt
.\nssm.exe restart WeldTeamMES             # или перезапуск ЗАПУСК.bat
```
Схема БД обновляется сама при старте (Alembic-миграции). **Файл `data\welding_shop.db`
при обновлении НЕ трогается** — данные на месте.

---

## Резервные копии базы

Раз в день/неделю копируйте `C:\WeldTeam\data\welding_shop.db` в надёжное место
(это один файл — вся база). Перед крупными операциями бэкап делается автоматически
в `backups\`, но регулярные копии на другой диск/сеть — на вашей стороне.

---

## Если сайт не открывается с других ПК

- Проверьте, что сервер и устройство в одной сети (одинаковый префикс IP).
- Проверьте правило брандмауэра (шаг 8).
- Убедитесь, что служба/окно запущено (шаг 7/9).
- На сервере `http://127.0.0.1:5000` работает, а по IP нет — почти всегда дело в
  брандмауэре или в том, что устройства в разных подсетях.
